# Sitio institucional de AUDITTIA
1. El sitio multipágina usa HTML y CSS estático; no requiere instalación ni compilación.
2. Antes de publicar, reemplaza [NOMBRE_PADRE], [NOMBRE_HIJO] y [CORREO_CONTACTO].
3. Sustituye [MÉTRICA_PENDIENTE_VALIDACIÓN: tiempo actual por cuenta de alta complejidad] solo con datos verificados.
4. Sustituye [MÉTRICA_PENDIENTE_VALIDACIÓN: tiempo con la plataforma por cuenta de alta complejidad] solo con datos verificados.
5. Sustituye [MÉTRICA_PENDIENTE_VALIDACIÓN: reducción de tiempo por cuenta de alta complejidad] solo con datos verificados.
6. Las páginas temáticas son plataforma, entidades, seguridad, nosotros, recursos y privacidad.
7. Completa privacidad.html con asesoría jurídica antes de publicarla como política definitiva.
8. En Vercel, importa esta carpeta como proyecto y elige “Other” como framework, sin comando de build.
9. Deja el directorio de salida vacío (raíz del proyecto) y ejecuta Deploy.
